# potential-octo-pancake

A lightweight static test website for validating basic hosting, styling, and browser JavaScript behavior.

## Files

- `index.html` - page structure and content
- `styles.css` - responsive styling
- `script.js` - interactive counter behavior

## Run locally

Open `index.html` in a browser, or serve the directory with a static file server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.
